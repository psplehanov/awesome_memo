# awesome_memo

Попап Awesome WM с одной случайной активной запиской из каталога markdown-файлов. Вызывается горячей клавишей, которую пользователь назначает сам; при старте Awesome ничего не показывается и в wibar ничего не добавляется.

## Требования

- Awesome WM 4.3+ (Lua 5.3).
- Стандартные модули Awesome: `awful`, `wibox`, `gears`, `beautiful`, `naughty`.
- `lfs` входит в поставку Awesome, отдельно ставить не нужно.

## Установка

Скопируйте или слинкуйте модуль в каталог виджетов Awesome:

```bash
ln -s ~/git/awesome_memo/memo_popup.lua ~/.config/awesome/widgets/memo_popup.lua
```

В `~/.config/awesome/rc.lua` подключите модуль и назначьте клавишу (пример — `Mod4+m`):

```lua
local memo = require("widgets.memo_popup")({
    path = "~/vault/memos",
})

awful.key({ modkey }, "m", function()
    memo:show()
end, { description = "memo", group = "awesome" })
```

`awful.key` добавляется в `globalkeys` так же, как остальные глобальные привязки. Клавиша может быть любой, включая `Mod4+s`, если она свободна.

## Управление

| клавиша | действие |
|---|---|
| `Esc` | закрыть попап |
| `r` | показать другую активную записку |
| `e` | открыть текущий файл в редакторе |
| `Space` | переключить `active` / `inactive` |
| клик по кнопке ответа | показать правильный ответ |

Клик вне попапа и необработанные клавиши ничего не меняют.

## Формат записки

Файл — markdown с необязательным frontmatter:

```markdown
---
status: active
topic: Тема напоминания
---
{memo}Текст напоминания, может занимать
несколько строк{/memo}

{button}неправильный ответ{/button}
{button}**правильный ответ**{/button}

Произвольный текст заметки
```

- `status: active` — записка участвует в выборе; `inactive` — нет.
- `topic` — заголовок; если пуст, берётся имя файла без `.md`.
- `{memo}...{/memo}` — отображаемый текст; несколько блоков склеиваются.
- `{button}...{/button}` — варианты ответа; `**...**` помечает правильный.
- Без тегов `{memo}` показывается весь текст вне кнопок; markdown не рендерится.
- Сканируется только сам каталог, без подкаталогов; читаются `*.md`.

## Настройки

| поле | по умолчанию | смысл |
|---|---|---|
| `path` | — (обязательно) | каталог записок, `~` раскрывается |
| `editor` | `nil` | команда редактора; иначе глобальная `editor_cmd`, иначе `alacritty -e nvim` |
| `width` | `480` | ширина попапа, px |
| `padding` | `12` | внутренние отступы, px |
| `font` | `beautiful.font` | базовый шрифт всех элементов |
| `fonts.topic` | значение `font` | шрифт заголовка |
| `fonts.memo` | значение `font` | шрифт текста напоминания |
| `fonts.button` | значение `font` | шрифт кнопок ответов |
| `fonts.hint` | значение `font` | шрифт нижней подсказки |
| `max_height_ratio` | `0.8` | доля высоты рабочей области |
| `max_text_height` | `320` | максимальная высота прокручиваемого текста |
| `colors.fg`, `colors.bg` | из `beautiful` | основные цвета |
| `colors.correct` | `#2e7d32` | подсветка правильного ответа |
| `colors.incorrect` | `#c62828` | подсветка неправильного ответа |

Заголовок записки отображается по центру попапа и обрезается многоточием, если не помещается по ширине. Любой неуказанный шрифт элемента берётся из `font`, затем из `beautiful.font`. Пустая строка или нестроковое значение игнорируются.

Пример с разными шрифтами:

```lua
local memo = require("widgets.memo_popup")({
    path = "~/vault/memos",
    font = "sans 10",
    fonts = {
        topic = "sans bold 14",
        memo = "sans 10",
        button = "sans 9",
        hint = "sans 8",
    },
})
```

## Тесты

Отдельного интерпретатора Lua в системе может не быть, тесты запускаются через Neovim:

```bash
./tests/run.sh
```

Проверяются парсер frontmatter и разметки, сканирование каталога, выбор записки, переключение статуса и UI-логика на заглушках Awesome.

## Ограничения

- Одновременно открыт один попап; он переносится на экран с фокусом.
- История показов между перезапусками Awesome не сохраняется.
- Markdown, картинки и ссылки не рендерятся.
- Записки не создаются и не редактируются внутри попапа.
